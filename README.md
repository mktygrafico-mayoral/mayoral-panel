# Mayoral Panel de Gestión

Sistema de gestión de contenido digital y solicitudes de diseño para Muebles Mayoral.

## Archivos

- `index.html` — Panel público de gestión (compartir con supervisora y equipo)
- `dashboard.html` — Dashboard personal (solo uso interno)

## Tecnología

- HTML/CSS/JS puro — sin frameworks
- Supabase como base de datos en la nube
- GitHub Pages para hosting gratuito
